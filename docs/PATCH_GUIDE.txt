 라쿠가키 쇼타임 PS1 한글 패치 + 7개 영상 자막 (2026-08-11)
 대상: 일본판 SLPM-86272

■ 구성과 버전 선택

  apply_cheat.cmd
      한글 패치와 7개 영상 자막을 적용하고 모든 캐릭터·특수 옵션을 해금합니다.
      출력: <원본 이름>_KR_MOVIES_CHEAT.bin / .cue

  apply_no_cheat.cmd
      같은 한글 패치·영상 자막을 적용하되 원작의 해금 진행을 유지합니다.
      출력: <원본 이름>_KR_MOVIES_NO_CHEAT.bin / .cue

두 CMD는 apply_patch.ps1과 tools\xdelta3.exe를 자동 호출합니다. 원본이나 완성
BIN은 배포물에 포함되지 않습니다.


■ 1. 지원 원본

  게임:    Rakugaki Showtime 일본판
  시리얼:  SLPM-86272
  트랙:    MODE2/2352 단일 BIN
  크기:    591,880,800 바이트
  SHA-256: 99DC6C7F748C4882D6F197A0A0A2EB943AFFC25BB4271DEFF9BB9BF55859AA54

다른 판본, ISO 변환본, 다중 BIN 변환본 또는 이미 수정된 BIN에는 적용되지
않습니다.


■ 2. 패치 적용 방법

원하는 CMD 위로 원본 일본판 BIN을 끌어다 놓으세요. 별도 프로그램 조작은
필요하지 않습니다.

  자동 해금판: apply_cheat.cmd
  원작 진행판: apply_no_cheat.cmd

명령 프롬프트에서는 다음처럼 실행할 수 있습니다.

  apply_cheat.cmd "Rakugaki Showtime (Japan).bin"
  apply_no_cheat.cmd "Rakugaki Showtime (Japan).bin"

입력·출력 SHA-256 확인, xdelta 적용, 결과 BIN 검증과 MODE2/2352 CUE 생성이
자동으로 수행됩니다. 에뮬레이터에서는 생성된 CUE를 여세요. 원본 BIN은 수정하지
않습니다.

■ 4. 적용 내용

  · 게임 내 텍스트 388행과 한글 460자 전용 글꼴
  · 메뉴·옵션 라벨 그래픽 52개와 대형 UI 표시
  · 타격 효과와 캐릭터 선택 Team/Color 라벨
  · BAD, GOOD, NE_A, NE_B, NE_C, NE_D, OPEN 7개 영상의 현재 한국어 자막
  · 치트 적용판에만 모든 캐릭터와 특수 옵션 자동 해금

영상의 XA 오디오는 일본어 원음을 그대로 보존했습니다. 자막 삽입은 비디오
Form 1 섹터에만 적용되며 영화의 LBA, 섹터 수, 프레임 수와 XA Form 2 오디오는
원본과 같습니다.


■ 5. 영상 자막 검토 상태

BAD 자막은 사용자 승인본입니다. GOOD·NE_A·NE_B·NE_C·NE_D·OPEN에는 현재
청취·기계 전사로 정리한 초벌 문장도 포함되어 있어 일부 대사가 누락되거나 문구가
부정확할 수 있습니다. 이번 판본은 사용자가 요청한 현재 7개 영상 자막 통합 검증용
빌드입니다.

OPEN 초반 영상에 직접 그려진 일본어 효과 문자는 아직 한국어 그래픽으로 교체하지
않았습니다.


■ 6. 검증 범위

  · 7개 후보 STR 전편 디코드와 원본 프레임 수 일치
  · 모든 영상의 프레임 정렬 shift 0
  · XA 오디오 섹터 전체 byte-identical
  · 변경 비디오 섹터의 Mode 2 Form 1 EDC/ECC 검증
  · 최종 BIN의 7개 STR extent가 각 검증 후보와 byte-identical
  · 원본 대비 전체 변경 섹터 집합과 Expected Write 일치

정적 빌드와 xdelta/CMD 왕복 검증 뒤에도 DuckStation에서 7개 영상을 직접 재생해
자막, 음성 싱크, 건너뛰기와 종료 전환을 확인해야 최종 런타임 검증이 완료됩니다.


■ 7. 제거와 주의

원본 BIN/CUE를 다시 사용하면 됩니다. 패치 완료 BIN이나 원본 게임 이미지를
배포하지 마세요. 배포 가능한 파일은 xdelta 패치와 적용 도구·문서입니다.
