# 영상 통합 배포판 재빌드

대상은 `movies-20260811`의 치트판·치트 미적용판이다. 기존 번역문과 영상 포함 상태를 바꾸지 않고 동일한 BIN을 재현한다. 게임 내 글꼴·메뉴·문구·효과음 그래픽은 기존 소스와 번역 원장으로 빌드한다. 이미 인코딩된 자막 영상 7편은 원본 디스크의 각 STR 구간을 소스로 요구하는 차분으로 복원한다. 영상 인코더의 재실행 결과까지 동일하다는 주장은 하지 않는다.

## 입력과 실행

- Python 3.12.10 검증 환경. `python -m pip install -r requirements-rebuild.txt`.
- 외부 xdelta3 실행 파일.
- 보유한 일본판 원본 BIN/CUE. BIN은 591,880,800바이트, SHA-256 `99dc6c7f748c4882d6f197a0a0a2eb943affc25bb4271deff9bb9bf55859aa54`.
- 동일 글꼴 4개: `Galmuri11-Condensed.ttf`, `Galmuri9.ttf`, `RiaSans-Bold.ttf`, `neodgm.ttf`. 크기·SHA-256은 `assets/rebuild/profile.json`에 있다. 글꼴은 외부 입력이며 Git에 포함하지 않는다. 기존 `Font/` 또는 비공개 편집 백업의 `fonts/`에 보존한다.

```powershell
python -X utf8 workspace/scripts/rebuild_release.py `
  --source-bin 'D:\Owned\Rakugaki Showtime (Japan).bin' `
  --source-cue 'D:\Owned\Rakugaki Showtime (Japan).cue' `
  --font-dir 'D:\Fonts' `
  --xdelta 'D:\Tools\xdelta3.exe'
```

새 `build/rebuild_<시각>/`에서 격리 빌드를 수행하며 기존 원본·게임 폴더·세이브를 수정하지 않는다. `--output`으로 아직 존재하지 않는 별도 경로를 지정할 수도 있다. `verification.json`의 PASS와 로그를 확인한다.

## 검사와 경계

원본·글꼴·자막 CSV·차분·복원 STR의 해시를 검사한다. 원본 BIN에서 ARA/HAGECHO를 추출하고 두 기본판을 소스 빌드한다. 영상 변경은 비디오 섹터로 한정하고 XA 및 다른 비디오 외 데이터의 일치를 검사한다. 영상 프레임 번호, raw 헤더, Form 1 EDC/ECC, 쓰기 계획 중복 및 최종 전체 차이 집합을 검사한 뒤 위 BIN 해시와 대조한다.

`assets/rebuild/`에 기존 빌드에 필요한 분석 자료와 실제 배포에 사용한 자막 CSV를 보존했다. BAD는 `approved`, 나머지 6편은 기존의 `review_needed`/`translated` 포함 정책을 그대로 계승한다. 이번 검증으로 자막을 새로 승인하거나 교정하지 않았다. 번역 원장 324행과 기존 배포 ZIP·태그를 변경하지 않았다.

이번 검증은 정적·소스 빌드·차분 복원·패치 적용 범위다. 영상 7편의 새 에뮬레이터 재생 검수와 전체 플레이는 수행하지 않았다. 기존 문서의 runtime pending 기록을 완료로 바꾸지 않는다.

개발 당시 원본·외부 도구·중간 미디어 경로에 의존하는 역사적 스크립트 전체의 재현을 뜻하지 않는다. 영상 재전사 도구의 기존 소스는 `work/tools/*.py`에 보존했지만 ASR 모델·가상환경·JRE는 외부 의존성이다.

로컬 게임 폴더는 사용자 요청에 따라 재현·백업 검증 후 삭제했다. [삭제·복원 인계](HANDOFF_2026-10-16.md)에 보존 위치와 근거를 기록했다.
